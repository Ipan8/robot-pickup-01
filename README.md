One pickup line, in the voice of a robot trying to charm someone:

> Are you Wi-Fi? Because I feel a strong connection — and for once, I don't need a password.

The robot's whole life is handshakes, tokens and passwords. This is the one connection that just works.

## Run

```sh
npx tsx main.ts
```

Writes the entry line to `/output/entry.txt`.
